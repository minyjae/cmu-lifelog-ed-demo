# CMU Lifelong Ed Rework

โปรเจกต์สำหรับปรับปรุง/ทดลองเนื้อหาและโค้ดของหลักสูตร "Lifelong Education" ของมหาวิทยาลัย ชุมนุมตัวอย่างและเครื่องมือที่เกี่ยวข้อง

จุดประสงค์
- เก็บตัวอย่างโค้ด เอกสาร และสาธิตการใช้งานสำหรับการสอนระยะยาว
- ใช้เป็นฐานทดลองสำหรับสลับเนื้อหาและแสดงตัวอย่าง

เทคโนโลยีที่ใช้ (ตัวอย่าง)
- ภาษา: Go / Node.js / Python (ขึ้นกับโฟลเดอร์ย่อย)
- เครื่องมือ: Docker, Docker Compose (ถ้ามี), Makefile (ถ้ามี)

โครงสร้างโฟลเดอร์ (ตัวอย่าง)
- `cmd/` — จุดเริ่มต้นของแอปหรือบริการ
- `internal/` — โค้ดภายในที่ไม่เปิดเป็น public API
- `pkg/` — ไลบรารีที่สามารถนำไปใช้ซ้ำได้
- `docs/` — เอกสารประกอบ

ข้อกำหนดเบื้องต้น
- Git
- Go/Node/Python (ตามโปรเจกต์ย่อย)
- Docker (ถ้าต้องการรันแบบคอนเทนเนอร์)

การติดตั้งและรัน (ตัวอย่างทั่วไป)
1. คลอนโปรเจกต์

```bash
git clone <repo-url>
cd CMU-LIFELONG-ED-REWORK
```

2. รันด้วย Docker Compose (ถ้ามี)

```bash
docker-compose up --build
```

3. รันแบบ local (ตัวอย่าง Go)

```bash
go run ./cmd/your-app
```

การมีส่วนร่วม
- เปิด Issue เพื่อเสนอฟีเจอร์หรือบั๊ก
- สร้าง PR พร้อมคำอธิบายและการทดสอบที่เกี่ยวข้อง

ติดต่อ
- ถ้าต้องการให้ช่วยเติมตัวอย่างการรันเฉพาะภาษา หรือเพิ่มตัวอย่าง request/response ให้บอกได้เลย
